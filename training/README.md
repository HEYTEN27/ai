# Дообучение Джарвиса

| Файл | Что это |
|---|---|
| `colab_finetune.ipynb` | **Основной путь.** Ноутбук для Google Colab (бесплатная Tesla T4): QLoRA для Qwen3 8B в fp16 через Unsloth → GGUF Q4_K_M → Google Диск |
| `train_local.py` | Экспериментально: обучение на своей видеокарте. На 8 ГБ — только Qwen3-4B |

## Быстрый путь (через приложение)

1. Соберите датасет: 👍 и ✏️ под ответами в чате (страница «Датасет», желательно 200+ примеров).
2. Страница **«Обучение»** → «Скачать пакет для Colab» (zip: датасет без дублей + ноутбук + настройки).
3. В [Google Colab](https://colab.research.google.com): *Файл → Загрузить блокнот* → `colab_finetune.ipynb`,
   *Среда выполнения → T4 GPU*, запускайте ячейки по порядку, загрузите архив, когда попросит.
4. Скачайте `jarvis-qwen3.Q4_K_M.gguf` с Google Диска (папка `jarvis/`).
5. «Обучение» → «Подключить обученную модель» → путь к файлу → «Подключить к Ollama».

Приложение загрузит файл в Ollama (`/api/blobs` + `/api/create`) и скопирует шаблон чата
с `qwen3:8b` — без этого у новой модели не работали бы инструменты и «размышления».

## Почему не на своей видеокарте

Qwen3 8B в 4 битах: слои ≈ 4 ГБ + два слоя словаря (151 тыс. слов × 4096 — не сжимаются) ≈ 2,5 ГБ
+ активации и оптимизатор. На RTX 2060 Super свободно ≈ 7,3 ГБ — не помещается.
Qwen3-4B помещается при контексте 1024 и закрытой Ollama:

```bat
ollama stop qwen3:8b
python training/train_local.py --dataset data/dataset/train_sft.jsonl
```

Скрипт сам проверит свободную видеопамять и откажется запускаться, если её мало (`--force` — всё равно попробовать).
Turing (RTX 20xx) не умеет bfloat16 — обучение идёт в float16.

## Если стало хуже

- Модель повторяет примеры дословно или «тупит» на новых вопросах — переобучилась: уменьшите `EPOCHS`.
- Эффекта не видно — мало или однообразные примеры: соберите больше разных.
- Сравнивайте честно: те же вопросы, кнопка «Повторить» с другой моделью.
