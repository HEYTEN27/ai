# Джарвис — личный локальный ИИ-ассистент

Чат-ассистент в стиле ChatGPT, который работает **целиком на вашем компьютере** через
[Ollama](https://ollama.com) с открытой моделью **Qwen3 8B**. Помнит факты о вас, отвечает по
вашим конспектам и заметкам Obsidian со ссылками на источник, считает, ищет в интернете,
запускает код — и учится на ваших оценках.

Проверено под Windows 10, RTX 2060 Super (8 ГБ), Ryzen 5 2600, 16 ГБ RAM.

## Возможности

| | |
|---|---|
| 🤵 **Джарвис** | голографический интерфейс с «ядром», которое думает и говорит; заставка запуска; «Да, сэр» — обращение настраивается; ответы озвучиваются офлайн-голосом Windows |
| 💬 **Чат** | потоковые ответы, история диалогов, markdown и подсветка кода, «Стоп» и «Повторить», «размышления» Qwen3, выбор модели, индикатор видеопамяти |
| 🎭 **Персоны и настройки** | имя и системный промпт, персоны (учитель, программист, редактор, свои) с температурой и другими параметрами, размер контекста с оценкой видеопамяти |
| 🧠 **Память** | сам замечает факты о вас («учусь на 2 курсе»), подставляет подходящие в ответы; страница «Память» с правкой и отменой |
| 📎 **Файлы в чате** | прикрепите PDF, Word, Excel, PowerPoint, текст или код прямо к сообщению — и спрашивайте по нему |
| 📝 **Документы** | Джарвис создаёт документы Word, презентации PowerPoint и таблицы Excel, правит ваш Word с сохранением оформления |
| 🎮 **Артефакты** | игры, интерактивные страницы, тренажёры и визуализации запускаются в панели рядом с чатом; схемы и рисунки — прямо в ответе |
| 📚 **База знаний** | PDF, DOCX, TXT, MD и папка Obsidian; ответы со ссылками [1] на фрагмент и страницу |
| 🛠 **Инструменты** | калькулятор, поиск в интернете, чтение файлов из выбранной папки, Python-песочница; действия с файлами — только с вашего разрешения |
| 👍 **Датасет** | 👍/👎 и «исправить ответ» под каждым сообщением → JSONL для обучения (SFT и DPO) |
| 🎓 **Дообучение** | ноутбук Google Colab (QLoRA) → GGUF → подключение к Ollama одной кнопкой |
| 🎙 **Голос** | голосовой ввод: Whisper распознаёт речь на этом компьютере; озвучка ответов голосом Windows |
| 💾 **Экспорт** | диалоги в Markdown и JSON, архив всех диалогов |

## Установка

Нужно один раз:

1. **[Ollama](https://ollama.com/download)** — программа, которая запускает модели.
2. **[Python 3.12](https://www.python.org/downloads/)** — при установке отметьте
   **«Add python.exe to PATH»**.
3. Код проекта:
   ```bat
   git clone https://github.com/HEYTEN27/ai
   ```

## Запуск — одна команда

**Windows:** дважды кликните **`start.bat`**. **Linux/macOS:** `./start.sh`.

Скрипт сам:
- создаст окружение Python и поставит пакеты (первый раз — несколько минут; дальше — только если
  изменился `requirements.txt`);
- запустит Ollama, если она не запущена;
- предложит скачать модель `qwen3:8b` (≈ 5,2 ГБ) и, по желанию, `bge-m3` (≈ 1,2 ГБ, поиск по смыслу);
- откроет интерфейс: **http://127.0.0.1:8000**.

Если ассистент уже запущен, `start.bat` просто откроет браузер. `start.bat --yes` — скачать всё
без вопросов. Остановить — закрыть окно консоли (или Ctrl+C).

Вручную, без скрипта: `pip install -r requirements.txt`, затем `python -m backend --open`.

## Что где в интерфейсе

- **Верхняя панель:** персона, модель, «Размышлять» (точнее, но медленнее), индикатор видеопамяти,
  🔊 озвучка ответов вкл/выкл, часы.
- **Над полем ввода:** где искать ответы — во всей базе знаний, в одной коллекции или нигде.
  Слева в поле — 📎 прикрепить файл (или перетащите файл в окно), справа — 🎙 голосовой ввод.
- **Под ответом:** модель и скорость, 🧠 сколько фактов из памяти учтено, источники [1],
  карточки инструментов и созданных документов, кнопки «Копировать», «Повторить», 🔊 «Прочитать вслух»,
  📄 «Скачать как Word», 👍 👎 ✏️.
- **Боковая панель:** диалоги (⤓ — скачать, ✎ — переименовать, 🗑 — удалить), страницы «Память»,
  «База знаний», «Датасет», «Обучение», ⚙ настройки.

### Память
Под ответом появится «💾 Запомнил: … · Отменить». Пароли, номера карт и телефонов не сохраняются
никогда. На странице «Память» факты можно искать, править, закреплять 📌 (подставляются всегда),
удалять и добавлять вручную; любое изменение отменяется в журнале.

### Файлы и документы
**Спросить по файлу.** Нажмите 📎 (или перетащите файл в окно, или вставьте Ctrl+V) — подходят PDF, DOCX,
XLSX, PPTX, TXT, MD, CSV и файлы с кодом до 25 МБ. Можно отправить без текста — Джарвис расскажет, что в
файле. Файл остаётся в диалоге: следующие вопросы тоже учитывают его.

Окно контекста модели — около 6 страниц текста. Небольшой файл Джарвис читает целиком, а из большого
берёт подходящие к вопросу фрагменты (под ответом «📎 1 файл» — при наведении видно, целиком или
выдержками). Для толстых учебников и сотен заметок лучше «База знаний»: она ищет по всем документам сразу.
Картинки и сканы пока не читаются — это будет на этапе «Зрение».

**Создать документ.** Попросите: «сделай реферат про … в Word», «презентацию на 8 слайдов про …»,
«таблицу Excel с бюджетом на месяц». Под ответом появится карточка с предпросмотром и кнопкой
«Скачать». Документ Word получается со стилями (заголовки, списки, таблицы) — в Word работает
автооглавление. Чтобы переделать: «добавь раздел про …» — Джарвис пересоздаст файл.

**Исправить ваш Word.** Прикрепите .docx и попросите: «замени 2025 на 2026», «исправь фамилию
Иванов на Петров». Джарвис создаст исправленную копию — оформление сохранится, оригинал не меняется.

**Любой ответ — в Word:** кнопка 📄 под ответом.

Файлы хранятся в `data/files` и удаляются вместе с диалогом. Выключить создание документов — ⚙ → «Инструменты».

### Артефакты: игры, страницы, схемы
Попросите: «сделай игру змейка», «интерактивный тренажёр таблицы умножения», «визуализацию сортировки
пузырьком», «3D-куб, который крутится мышкой», «график расходов», «схему процесса регистрации».

- **Игры и страницы** открываются в панели справа (на телефоне — поверх чата). Вкладка «Код», версии
  («Версия 1, 2, 3» — каждая правка), перезапуск, на весь экран, скачать .html. Ширину панели можно менять,
  потянув за её левый край.
- **Песочница.** Код от модели работает изолированно: без доступа к приложению, вашим диалогам и
  интернету. Внешние библиотеки из интернета не загрузятся — зато Three.js (3D) и Chart.js (графики)
  лежат в проекте и подключаются сами.
- **Ошибка в игре?** Панель покажет её с номером строки — нажмите «🛠 Исправить», и Джарвис получит описание.
- **Схемы (Mermaid) и рисунки (SVG)** видны прямо в ответе; в панели — крупно, можно скачать как .svg.

Честно про 8K контекста: полная игра на 300 строк — это ≈ 3–4 тыс. токенов, а при правке модель читает
старую версию и пишет новую целиком. Поэтому в контекст идёт только последняя версия кода, а если ответ
всё-таки оборвался, карточка скажет «код оборвался». Для больших игр поставьте в ⚙ контекст 16K вместе
со сжатием KV-кэша q8_0 (помещается в 8 ГБ).

### База знаний
Загрузите файлы или подключите папку (например, `C:\Users\имя\Documents\Obsidian Vault`) — после
правок заметок нажмите «Синхронизировать». Поиск гибридный: по смыслу (`bge-m3`) и по словам.
«Проверить поиск» показывает, какие фрагменты получит модель. Сканы PDF без текста не поддерживаются.

### Инструменты
Модель сама решает, когда нужен инструмент. Чтение файлов — только из папки, выбранной в
⚙ → «Инструменты», и **каждое** чтение вы подтверждаете кнопкой. Запуск кода по умолчанию тоже с
подтверждением: песочница без Docker защищает от случайностей, но не от целенаправленной атаки.

### Датасет и дообучение
👍 — хороший ответ попадает в датасет, ✏️ — исправленная версия становится образцом (и модель видит
её дальше в диалоге). Файлы `data/dataset/train_sft.jsonl` и `train_dpo.jsonl` обновляются сами.
Когда наберётся 150–200+ разнообразных примеров — страница «Обучение»: пакет для Google Colab →
обучение (~10–20 мин на бесплатной T4) → `jarvis-qwen3.Q4_K_M.gguf` → «Подключить к Ollama».
Подробно — [training/README.md](training/README.md).

### Интерфейс «Джарвис»
По умолчанию включено голографическое оформление: светящееся «ядро» в центре вращается спокойно,
пока ассистент ждёт, ускоряется, когда он думает, пульсирует, когда говорит, и становится янтарным,
когда слушает микрофон. При первом открытии за сессию показывается короткая заставка с проверкой
систем (модель, память, база знаний) — пропускается любой клавишей или кликом.

Персона **«Джарвис»** (по умолчанию) отвечает в манере вежливого ИИ-дворецкого: «Да, сэр.»,
«Сию минуту, сэр.». Как к вам обращаться («сэр», «мисс», «босс», имя) и оформление
(голографическое или классическое тёмное) — ⚙ → «Основное». Обычный стиль без «сэр» — персона
«Универсальный».

**Озвучка ответов.** Джарвис читает ответы вслух голосом, встроенным в Windows, — **без интернета**
(сетевые голоса Google не используются: они отправляют текст в интернет). Код не зачитывается:
«Код — на экране». Если русского голоса нет, кнопка 🔊 не появится. Как добавить голос:
**Параметры → Время и язык → Речь → «Добавить голоса» → Русский** (появятся «Microsoft Pavel» —
мужской и «Irina»), затем перезапустите браузер. Голос, скорость, звуки интерфейса — ⚙ → «Голос и данные».

### Голос
Нажмите 🎙, скажите фразу, нажмите ещё раз — текст появится в поле ввода (его можно поправить
перед отправкой). Esc — отменить запись. При первой записи скачается модель распознавания
(`small`, ≈ 480 МБ). Модель и язык — ⚙ → «Голос и данные».

## Железо и видеопамять

На 8 ГБ видеопамяти Qwen3 8B помещается целиком (≈ 5,9 ГБ при контексте 8K), но запас небольшой:

- Индикатор вверху справа: зелёный «GPU 100%» — всё хорошо; жёлтый — часть модели в оперативной
  памяти, ответы в разы медленнее.
- Браузер с кучей вкладок, игры и **Wallpaper Engine** тоже занимают видеопамять — их лучше закрыть
  или поставить на паузу.
- Контекст больше 12K без сжатия кэша не поместится. Сжатие (вдвое меньше памяти, качество почти
  то же) включается в Ollama: переменные среды `OLLAMA_FLASH_ATTENTION=1` и `OLLAMA_KV_CACHE_TYPE=q8_0`
  (инструкция — ⚙ → «Основное» → «Сжатие KV-кэша»).
- `bge-m3` и Whisper работают на **процессоре**, чтобы не отнимать видеопамять у основной модели.
- Модели крупнее 8B в списке помечены «медленно, частично на CPU».

## Что выходит в интернет

Всё работает офлайн, кроме:
- **поиска в интернете** (запрос уходит DuckDuckGo или вашему SearXNG) — можно выключить в ⚙ → «Инструменты»;
- **обучения в Google Colab** — датасет загружаете туда вы сами;
- **скачивания** моделей (Ollama, Whisper при первой записи) и пакетов Python — один раз.

Телеметрии нет. Сервер слушает только `127.0.0.1` — с других компьютеров он недоступен.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| «Ollama недоступна» | Запустите Ollama (значок в трее) — интерфейс подхватит её сам. Не установлена — [ollama.com/download](https://ollama.com/download) |
| «Модель не найдена» | `ollama pull qwen3:8b` |
| Ответы очень медленные, индикатор жёлтый | Модель не помещается в видеопамять: закройте лишнее, уменьшите контекст в ⚙, включите сжатие KV-кэша |
| «Порт 8000 занят» | В файле `.env` (скопируйте из `.env.example`) укажите `PORT=8001` |
| Поиск в интернете выдаёт ошибку | Проверьте интернет и VPN; можно указать свой SearXNG в ⚙ → «Инструменты» |
| Нет кнопки 🔊 / Джарвис молчит | В Windows нет русского голоса: Параметры → Время и язык → Речь → «Добавить голоса» → Русский, перезапустите браузер |
| Не нравится «сэр» и голограммы | ⚙ → «Основное»: обращение, оформление «Классическое тёмное»; персона «Универсальный» — без дворецкого |
| Кнопки микрофона нет | ⚙ → «Голос и данные» → включить; если пишет «не установлено» — перезапустите `start.bat` |
| Нет доступа к микрофону | Значок слева от адреса в браузере → Микрофон → Разрешить |
| Первая запись голоса долгая | Скачивается модель распознавания (один раз) |
| Джарвис пишет документ в чат вместо файла | Попросите прямо: «создай файл Word». Проверьте ⚙ → «Инструменты» → «Документы». Модель без поддержки инструментов (не qwen3/llama3.1) файлы создавать не умеет |
| «Картинки Джарвис пока не видит» | Зрение появится на следующих этапах. Скан PDF без текстового слоя тоже пока не читается |
| Игра не запускается / «код оборвался» | Попросите «исправь» (кнопка в панели), упростите игру или увеличьте контекст до 16K (с q8_0) |
| В игре «заблокирован выход в сеть» | Так и задумано: артефакты работают офлайн. Попросите переписать без внешних ресурсов |
| База знаний не находит ответ | «Проверить поиск» на странице базы; без `bge-m3` работает только поиск по словам: `ollama pull bge-m3` |
| Странная ошибка после обновления | Перезапустите `start.bat` (доустановит пакеты). Данные в `data/` при обновлениях сохраняются |

## Настройки до запуска (`.env`)

Почти всё настраивается в интерфейсе. Файл `.env` (скопируйте из `.env.example`) нужен для того,
что задаётся до запуска: адрес Ollama, порт, движок (`LLM_BACKEND=llamacpp` — работать через
`llama-server` вместо Ollama).

## Ваши данные

Всё хранится в папке **`data/`** (в git не попадает): `assistant.db` — диалоги, память, настройки,
оценки; `knowledge/` — копии загруженных документов; `dataset/` — JSONL для обучения;
`models/` — модель распознавания речи. **Резервная копия — скопируйте папку `data/`.**
Экспорт диалогов — ⚙ → «Голос и данные».

## Устройство проекта

```
backend/                  сервер (Python, FastAPI)
  main.py                 сборка приложения из модулей
  config.py, db.py        настройки из .env, SQLite и миграции схемы
  llm/                    адаптеры Ollama и llama.cpp (общий интерфейс)
  chat/                   диалоги, сборка контекста и системного промпта, стриминг ответов (SSE), артефакты
  settings/               настройки, персоны, оценка видеопамяти
  memory/                 долговременная память: хранение, выбор фактов, извлечение из диалога
  knowledge/              база знаний: разбор файлов, нарезка, индексация, гибридный поиск
  tools/                  инструменты: калькулятор, файлы, песочница, веб, подтверждения
  dataset/                оценки, исправления, экспорт JSONL
  training/               пакет для Colab, подключение обученной модели к Ollama
  voice/                  распознавание речи (faster-whisper на CPU)
  export/                 экспорт диалогов в Markdown и JSON
  files/                  вложения в чате, создание Word/PowerPoint/Excel, правка Word
frontend/                 интерфейс: HTML/CSS/JS без сборки, библиотеки в vendor/ (без CDN)
training/                 ноутбук Colab и локальный скрипт обучения
scripts/launcher.py       запуск одной командой
tests/                    тесты (pytest) и браузерные сценарии (tests/e2e/, Playwright)
```

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Тестам не нужны ни Ollama, ни видеокарта: вместо Ollama работает эмулятор `tests/fake_ollama.py`.
Его можно запустить и отдельно, чтобы посмотреть интерфейс без модели:
`python -m uvicorn tests.fake_ollama:app --port 11434`. Браузерные сценарии — [tests/e2e/README.md](tests/e2e/README.md).
